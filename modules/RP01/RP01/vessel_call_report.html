What this sheet contains

Every vessel call in one list — the uploaded Vessel Call Master for calls up to the go-live cut-off, and the live system for everything after it. The two never overlap, so rows are simply appended; the Source column says which side each row came from.

  • Actual rows are built from VCN01 (vessel call, parcels, cargo), LDUD01 (SOF timings, parcel ops) and VC01 (IMO, flag, GRT).
  • Only closed LDUDs are included — Closed and Partial Close.
  • Every timing is one cell, DD-MM-YYYY HH:MM, as in the legacy sheet.
  • Quantity MT is the master's quantity on master rows and the actual quantity logged in LUEU01 on actual rows, with Declared and Short-Closed shown alongside.
  • The system records a single cast off, reported under Sail Cast Off. The plain Cast Off column is master-only and is blank for actual rows.
